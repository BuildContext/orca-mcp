### 1.7 Unlink residual (honest)

Stripping the named ACL from `.git` stops **overwrite** of the file
contents (`>` / `open(O_WRONLY)`). It does **not** stop `unlink` +
`mkdir .git` while the checkout directory is `W_OK`. Sticky bit on the
checkout would block unlink of orca-owned `.git`, but it would also
block legitimate `rm` of 997-owned tracked files. We do **not** set
sticky. The gitdir-pointer guard is the control for unlink/replace:
997 refuses to run git if `.git` is a directory, a symlink, or a
pointer that is not the expected
`/home/orca/src/<repo>/.git/worktrees/<name>` path.

## 5. Operator remediation for **pre-existing** worktrees

**This change does not rewrite ACLs on trees that already exist.** 994
cannot. After deploy, uid **997** (`orca`) must run the following once,
or every existing checkout stays 994-writable and new trees will keep
inheriting the parent default.

Do **not** use sudo. 997 is the owner.

```bash
WORKSPACES=/home/orca/orca/workspaces
WORKER=orca-worker

# 1) Drop the named user ACL and every default ACL under workspaces.
#    After this line, 994 cannot write any existing worktree until step 2.
setfacl -R -x "u:${WORKER}" "${WORKSPACES}"
setfacl -R -k "${WORKSPACES}"

# 2) Re-grant ONLY live in-flight worker checkouts (skip trash / idle).
#    For each live $WT:
setfacl -m "u:${WORKER}:rwx" -d -m "u:${WORKER}:rwx" "$WT"
# children except .git (never recurse into a .git directory):
find "$WT" -mindepth 1 -maxdepth 1 ! -name .git \
  -exec setfacl -R -m "u:${WORKER}:rwx" -d -m "u:${WORKER}:rwx" {} +
setfacl -x "u:${WORKER}" "$WT/.git" 2>/dev/null || true
chmod 0644 "$WT/.git" 2>/dev/null || true

# 3) Prove the parent default is gone:
getfacl -p "${WORKSPACES}"
# must NOT show default:user:orca-worker

# 4) Prove a foreign idle checkout has no named worker ACL:
getfacl -p "${WORKSPACES}/orca-mcp/nas262-259-recon-s6"
```

Until step 1 runs, the new create-time grant is redundant: the parent
default still paints every new file, including `.git`. The pointer strip
still helps on **new** trees (it removes the inherited named ACL from
`.git` after create). Foreign trees stay writable until step 1.
